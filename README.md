# Al-Harer — Premium Koofi Cap Store

A modern and responsive e-commerce website created for **Al-Harer**, a premium Koofi Cap brand focused on elegance, simplicity and quality.

## 🌐 Live Demo

https://alharer.netlify.app/

## ✨ Features

- Premium and modern product presentation
- Responsive design for desktop, tablet and mobile
- Product collection and best-sellers sections
- Product detail pages
- Shopping cart
- Checkout experience
- Account page
- Blog section
- About page
- Clean and user-friendly navigation
- WhatsApp customer communication
- Modern e-commerce interface
- Smooth and responsive user experience

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- Modern UI/UX
- Netlify Deployment

## 📱 Responsive Design

The website is optimized for:

- Desktop
- Laptop
- Tablet
- Mobile

## 🎯 Project Goal

The goal of this project was to create a clean, modern and premium online shopping experience for Al-Harer while keeping the interface simple, elegant and easy to use.
